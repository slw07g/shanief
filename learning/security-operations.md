This is a foundational track for anyone building the core skill set of a security operations career: triage, incident response, and offensive security. It is written for analysts, engineers, and anyone looking to break into the field, and it is built around the way the work actually happens, not the way it looks in a textbook.

Each track stands on its own. Work through them in order if you are new to the field. If you already have ground under you in one area, jump straight to the track you need.

## [Investigations & Triage](/learning/investigations-triage/)
How alerts get worked. Playbooks, the questions you ask before you touch a single log, where the evidence lives, and how you land on a disposition. Includes three full alert walkthroughs: user-reported phishing, EDR malware detection, and Okta suspicious activity.

## [Security Incident Response](/learning/incident-response/)
What happens once triage confirms impact. The difference between incident management and incident response, the six-phase lifecycle from detection to lessons learned, incident command structure, and the documentation that has to exist at the end: the executive summary and the postmortem.

## [Offensive Security](/learning/offensive-security/)
The attacker's side of the same problem. Attack methodology from reconnaissance to root, where to practice it (HackTheBox, TryHackMe), and how to get past the point where practice stops teaching you anything.

---

**How to use this material:** read the section, then apply it. Triage a real alert using the disposition framework. Run a postmortem on a real incident using the documentation templates. Root a box and write up the methodology instead of just moving to the next one. The material is the same whether you read it or skip it. What separates people is whether they used it.
